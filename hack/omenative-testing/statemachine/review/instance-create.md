## ROOT CAUSES

| root cause (file:function) | exceptions it explains | one-line fix shape |
|---|---|---|
| `pkg/controller/v1beta1/workload/query/discover.go:AllPodsRuntimeReady` (+ the unfiltered pod buckets `ops/create.go` reads) | pod.containersReady promote, pod.terminating, part of pod.stuckTerminating | filter or explicitly reject DeletionTimestamp-bearing pods in both the completeness diff and the readiness check |
| `pkg/controller/v1beta1/workload/status_aggregate.go:terminalPullFailureReasons` — the only permanence classifier in the pass | pod.unschedulable, pod.phaseTerminal, pod.waiting[DeadlineExceeded], gang.podGroup[Unschedulable/ScheduleTimeout/PhaseFailed] | widen the classifier to a permanence predicate over PodScheduled, pod phase and PodGroup status, not just container waiting reasons |
| `pkg/controller/v1beta1/workload/ops/create.go:createPodsForInstance` (wraps every non-AlreadyExists failure as an opaque `podCreateError`, no event) | api.quotaDenied, api.invalid, api.namespaceTerminating | classify the apierror (quota / invalid / namespace-terminating) into a typed reason, emit a Warning, and escalate the permanent ones |
| `pkg/controller/v1beta1/inferencereplica/reconciler.go:Reconcile` (returns EnsurePodGroups errors before `workload.Reconcile`) | gang.podGroup[OwnershipConflict] | let the pass run so the deadline and escalation still apply, and record the conflict as the row's blocking reason |
| `pkg/controller/v1beta1/workload/plan_decision.go:Plan` (pause truncates before Create; `planUnbackedDemotions` covers only Ready rows) | spec.pauseTrue, spec.pauseFreeze | extend the paused truth pass to transient rows so a held attempt reports Paused instead of Creating |

| `pkg/controller/v1beta1/workload/ops/create.go:retireSupersededCreateMutation` (Phase=Failed, no LastFailure, no event) | spec.revision before, spec.rollbackTarget before | stamp a Superseded reason (or a non-Failed retirement state) and charge no RetryBlock |
