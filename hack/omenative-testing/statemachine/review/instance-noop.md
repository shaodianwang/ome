## EXCEPTIONS (cells that contradict their event's meaning, an arrow, or the rubric; include every DECIDE and every # GAP cell of these states)

|---|---|---|---|---|
| E1. Ready · pod.phaseTerminal[Succeeded,Unknown] · all · — | ignore (# GAP) | the detector compares against PodFailed alone and the pod object still exists, so the row keeps claiming Ready with no live runner and Create sees no missing ordinal — truthfulness and liveness both broken, with no deadline | transition to Restart/Drain under RecreateInstanceOnPodRestart; escalate past the grace under None | code fix — restart.go detector |
| E2. | E3. | E4. Ready · timer.stuckPodGrace · all · T-ready-stuckgrace | escalate | same dead guard as E3 on the timer edge: the grace arms a shape whose precondition a Ready row cannot satisfy | as E3, so the two edges stay consistent | code fix — escalation.go |

| E6. | E7. Ready · spec.revision · all · T-ready-inplaceonly-reject | reject | the rejection is a returned error: a permanent user error retried on exponential backoff forever, event-only with no condition, and the error aborts the remaining passes for the whole Component | record a Held RetryBlock / RolloutHold and return nil so other indices keep progressing | code fix — ops/update.go |
| E8. | E9. | root cause (file:function) | exceptions it explains | one-line fix shape |
|---|---|---|

| `workload/ops/restart.go:DetectRestartTriggerWithPods` — reads only `PodFailed` and runner-restart-after-ReadySince | E1, E2 | add PodSucceeded / PodUnknown, and a not-ready-for-N trigger |
| `workload/plan_decision.go:Plan` — the restart pass appends every triggered Instance in one unpaced, ungated action; pause truncates the action list before Create; the create deferral resolves only on the next tick | E9, E18, E21 | pace ActionRestart with the unavailability budget; decide pause-vs-self-heal explicitly |
| `workload/plan_decision.go:planUnbackedDemotions` + `ops/demote.go` — Pending is by construction zero-live-pods and non-Recreate-policy only | E5, E6, E19 | delete the unreachable Pending edges, or state the policy-flip precondition |
| no apierrors classifier anywhere in `workload/` or `inferencereplica/` — `IsInvalid`, Retry-After and `namespaceTerminating` have no call site | E14, E15 | one `classify(err)` helper: terminal → Failed/condition, retriable → honored backoff |

| `workload/ops/create.go` — the diff only adds missing expected pod names (never removes), and the promote gates on ContainersReady | E10, E11, E20 | delete surplus ordinals; align the promote bar with the surge/recreate promotes |
| `workload/ops/update.go:Update` — InPlaceOnly ineligibility records a warning and returns an error | E7 | record a Held RetryBlock and return nil so the pass continues |
| `workload/ops/delete_batch.go:selectDeleteBatch` — `ScaleDownPodBatchSize` is an optional pacing batch, not an availability floor, and the wave consults no gate | E8 | add a floor check, or make the table say plainly that none exists |

| `workload/retryblock_prune.go` — a `Held` block is pruned only when superseded by a different target | E17 | keep the semantics; require the hold to name the operator action it waits on |
