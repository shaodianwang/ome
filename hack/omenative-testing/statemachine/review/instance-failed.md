## ROOT CAUSES
| root cause (file:function) | exceptions it explains | one-line fix shape |
|---|---|---|
| `pkg/controller/v1beta1/workload/ops/create.go:missingPodTargets` — presence is tested by pod *name* only | pod.stuckTerminating, pod.nodeLost, pod.unschedulable, pod.phaseTerminal[Failed], pod.phaseTerminal[Succeeded/Unknown] | treat a name-holding pod that is terminal, unschedulable past a configured grace, or Terminating past its grace as missing: reap it, then recreate under the same name |
| `pkg/controller/v1beta1/workload/ops/create.go:createFilteredBatched` Ready branch (`createStatusReadyMutation`) — promotes any complete+ContainersReady index regardless of phase, revision or preserved operation | missing Failed→Ready arrow, pod.containersReady[source], pod.servingOn[source], ctrl.resync | model the arrow in the table, and make the promotion refuse to clear a preserved non-Create operation |
| `pkg/controller/v1beta1/workload/ops/create.go:allowCreateForMissingInstance` — `freshStart` excludes any row with a preserved operation, so the RetryBlock gate is skipped; `createStatusCreatingMutation` then overwrites that operation | missing Failed→Create arrow, gate.deny[RetryBlock], ctrl.resync | gate on `Phase == Failed` regardless of the preserved operation, and never overwrite a non-Create operation from the Create pass |
| `pkg/controller/v1beta1/workload/escalation.go` (skip `Phase == Failed`) + `deadline.go:deadlineFailedMutation` (never re-arms) | the whole `failed.is.sticky` family; the no-deadline half of pod.stuckTerminating / pod.nodeLost / pod.unschedulable / gang.podGroup | keep the one-stamp-per-escalation rule, but arm a bounded, condition-visible clock for a Failed row that still owns live pods |
| `tests/rolloutspec` grid key is (state, event, variant, window) while `transitions.yaml` gives Failed four same-key corrective and four same-key retry edges | pod.deleted[target]·before, spec.revision·before, timer.retryAt·before, spec.rollbackTarget·before | split those four cells by `transition:` and move the strategy/trigger discriminator into each guard |
| `pkg/controller/v1beta1/workload/ops/update_gang.go:gangSurgeUpdate` — the `src.Phase == Failed` abandon branch runs before, and without, the readiness spare the supersede branch applies | pod.containersReady[target] | reuse the supersede branch's "complete and `AllPodsRuntimeReady`" test before abandoning a replacement gang |
